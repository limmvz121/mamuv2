Langkah Menjalankan Backend LK21-API

1. Ekstrak & Masuk ke Folder Project API

cd lk21-api-master
cp .env.example .env

2. Install Dependensi & Jalankan Server (Port 8080)

npm install
npm run build
npm start

3. Hubungkan ke Website MovieID

Setelah server aktif di http://localhost:8080 (atau domain hosting seperti Render/Railway/VPS), buka menu Konfigurasi Server API di atas dan klik Hubungkan & Muat Ulang Data.

✨ Berhasil disimpan!
